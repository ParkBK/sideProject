# 청년정책 (Youth Policy)

청년정책에 관한 **검증된 정보 정리, 변경 기록, 아이디어**를 모으는 공간입니다.
외부에 공개되는 저장소이므로 아래 원칙을 지킵니다.

## 작성 원칙

1. **출처 필수** — 모든 사실 정보에는 1차 출처(법령, 정부·지자체 공고, 공식 보도자료)를 링크합니다. 블로그·커뮤니티 글은 1차 출처로 쓰지 않습니다.
2. **기준일 명시** — 정책은 매년 바뀝니다. 모든 문서에 `기준일`(확인한 날짜)을 적습니다. 기준일이 1년 이상 지난 문서는 재확인 대상입니다.
3. **사실과 의견 분리** — 사실은 `policies/`·`records/`에, 해석·제안은 `ideas/`에 둡니다. 한 문서 안에서 섞어야 한다면 `> 의견:` 인용 블록으로 구분합니다.
4. **"청년" 정의 명시** — 청년의 연령 기준은 정책마다 다릅니다(예: 청년기본법 19~34세, 지자체·개별 사업은 39세 등). 각 문서에 해당 정책의 기준을 적습니다.
5. **개인정보 금지** — 실명, 연락처, 개인 신청 내역 등은 올리지 않습니다.

## 폴더 구조

| 폴더 | 용도 | 성격 |
|---|---|---|
| `policies/` | 개별 정책 정리 (대상, 지원 내용, 신청 방법, 출처) | 사실 |
| `records/` | 정책 신설·변경·폐지, 예산, 관련 뉴스 등 시점별 기록 | 사실 |
| `ideas/` | 문제 제기, 개선 제안, 분석 | 의견 |
| `_templates/` | 문서 작성용 템플릿 | - |

## 파일 이름 규칙

- `policies/`: `정책명.md` (예: `청년도약계좌.md`)
- `records/`: `YYYY-MM-DD-주제.md` (예: `2026-09-29-예산안-발표.md`)
- `ideas/`: `YYYY-MM-DD-주제.md`
